# 📊 Monthly Expense and Spending Pattern Analysis

## 📌 Project Overview
This project analyzes expense and supermarket transaction data to identify spending patterns, monthly trends, and customer purchasing behavior. The analysis helps in understanding expenses, tracking spending habits, and making data-driven financial decisions.

---

## 🎯 Objectives
- Analyze monthly spending trends.
- Calculate total and average expenses.
- Identify high-spending categories.
- Discover purchasing patterns.
- Visualize data using charts and graphs.
- Generate insights for better financial planning.

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset
The project uses the **SuperMarket Analysis.csv** dataset containing transaction and spending information.

### Features Used
- Date
- Expense Amount
- Product Category
- Customer Information
- Transaction Details

---

## 🔍 Project Workflow

### 1. Data Collection
- Load dataset using Pandas.

### 2. Data Inspection
- Check data types.
- Analyze dataset structure.
- Identify missing values.

### 3. Data Cleaning
- Handle missing values.
- Convert date columns.
- Create additional features such as:
  - Month
  - Day
  - Year

### 4. Exploratory Data Analysis (EDA)
- Total Expense Analysis
- Average Expense Analysis
- Monthly Spending Trends
- Category-wise Expense Distribution
- Spending Pattern Visualization

### 5. Data Visualization
The project includes:
- Bar Charts
- Line Charts
- Pie Charts
- Distribution Plots
- Trend Analysis Graphs

---

## 📈 Key Insights
- Identifies peak spending periods.
- Highlights major expense categories.
- Shows monthly spending fluctuations.
- Helps understand consumer purchasing behavior.
